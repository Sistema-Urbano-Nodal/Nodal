# NODAL privacy policy package

Prepared 19 September 2026 against repository revision `bd02dc4`.

**Status: public draft for organizational and legal review. Not adopted as a final policy.** This package supports a privacy program; it does not certify compliance with the LGPD or every Latin American law. Have counsel familiar with the controller's country and the countries actually served review it before adopting a final policy.

- [Portuguese policy](privacy-policy.pt-BR.md)
- [Spanish policy](privacy-policy.es.md)
- [English policy](privacy-policy.en.md)
- [Implementation review, country requirements and primary sources](implementation-review.md)

The three policy drafts use the same section order and placeholder identifiers. The public reading page at `/privacy.html` is generated by `node scripts/build-privacy-page.js`. It renders all three versions in advance and uses the existing saved language preference. The generator replaces unresolved template fields with explicit pending-confirmation wording and a link to the existing team contact section, without inventing a privacy officer or legal entity. The public notice identifies the page as a draft.

After editing any policy, regenerate the page and run `npm run build`; the tests check that the published content matches these sources.

## Decisions needed before final adoption

| Placeholder | Required decision or evidence |
| --- | --- |
| `{{CONTROLADOR}}` | Registered name of the entity deciding how NODAL uses data. Sistema Urbano is a candidate from project context, not a verified legal identity. |
| `{{REGISTRO_PAIS}}` | Country and company/nonprofit registration identifier, where applicable. |
| `{{ENDERECO}}` | Controller's business/contact address. |
| `{{CONTATO_PRIVACIDADE}}` | Working, monitored privacy email or request channel, available without signing in. Do not invent an email address. |
| `{{ENCARREGADO}}` | Identity and contact of the designated privacy lead/DPO, or a legally reviewed explanation of any applicable exemption. |
| `{{VIGENCIA}}` | Actual effective date after approval and publication. |
| `{{FORNECEDORES_TRANSFERENCIAS}}` | Completed list of actual vendors, legal entities, purposes, countries, onward transfers and applicable safeguards. Include SMTP and any hosted cache. |
| `{{RETENCAO}}` | Approved retention periods and triggers, including provider backups/logs and staff CSV copies. The suggested schedule in the review is not implemented. |
| `{{PUBLICO_ETARIO}}` | Intended age group, age-assurance approach and the response to minors already using the platform. |

Approval must also settle the purposes and legal bases by country, research uses, consent evidence, and who may access/export identifiable answers. An admin role in the application is not itself a legal designation as data controller or DPO.

## Evidence boundary

This was a source-code and official-law review. No production personal records, contracts, cloud-region settings, SMTP configuration, retention settings, or actual consent records were inspected in this task. The subsequent publication change adds a public reading page and footer links. It does not change database configuration, user permissions, consent collection, retention or deletion behavior.

The policy deliberately describes feedback as identifiable, distinguishes member-directory visibility from course discussions, explains the existing learned recommendation model, and avoids presenting future generative AI as an active service.

## Courses
Authenticated members see an editorial course directory and a course workspace. A vertical module route shows progress, session dates, materials, recordings, activities, and participant conversation. A clearly visible prototype label sets expectations. Enrollment is explicit and idempotent. An intake form records name, profession, city, motivation, previous mobility experience, expectations, case/territory, and digital/AI familiarity. Intake is private to the member and administrators. Published modules are visible to enrolled members; administrators can view drafts. Require intake before accessing module content. Users may post an assignment or question, attach an image/file/link, and reply to other submissions. Staff replies are labeled. Persistence survives refresh; writes have validation, ownership checks, same-origin and rate limits.

Staff can create/edit/publish/archive courses, create/edit/publish modules, attach resources/recordings, inspect enrollments and intake responses, moderate posts, see aggregated activity/feedback, and export CSV. Materials are authored by staff, not fictional content. Provide an idempotent explicit setup script for the real mobility pilot shell with the four known session dates. Use hosted links for recordings to avoid streaming videos through Vercel. File attachments have a 3 MB cap, validated allowed MIME/signatures, private storage (SQLite locally, Supabase Storage in production), authenticated downloads, and course enrollment authorization. No executable HTML/SVG uploads. Files are not embedded in feed JSON. Post pages use keyset pagination.

## Feedback and usage
A reusable 1–5 rating plus optional comment after profile completion, matching, course content/recording access, posting assignments or discussion. Durable feedback table, administrator-only view/export. Course events are explicit access records, not claims someone watched/read the full material. Dedupe event IDs, bound queries, index ownership and course/module/time lookups. Report registered participants, completed intake, module/content/recording access, assignments and comments. No AI metrics or placeholders.

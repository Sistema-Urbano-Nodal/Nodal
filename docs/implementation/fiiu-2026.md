# FIIU Fest in NODAL

## Brief and sources

Implement the September 28 request and Flavia's FIIU x NODAL board within the existing plain HTML/CSS/JavaScript and Node architecture. Source form: https://docs.google.com/forms/d/1zvj20L8MqH84WHh0XxsgGfEE1qhEF-X4RgO3QrPP8fk/edit. Event: https://fiiu.sistemaurbano.org/. Board: https://app.clickup.com/4209584/whiteboards/40exg-29877.

The public landing page is linkable before login. Registration uses the existing NODAL account and returns to the festival after authentication. One editable registration per account records five general conference blocks (October 21 morning/evening, October 22 morning/evening, October 23 morning). October 20 is an optional reviewed laboratory application for public officials, never automatic admission. Workshops, routes, closing party remain separately registered; administrators can configure their HTTPS links. Dates are local to Lima. Programme content may change; display the official programme link.

## Architecture and decisions

Dedicated festival domain, repository and API modules support both SQLite and Supabase. New tables hold private registrations, administrator-confirmed attendance, configurable links/open status, and published news/material links. New Supabase tables have RLS and server-only grants; ownership, administrator permission, same-origin protection, limits and optimistic versions are enforced at the application boundary. Account export and deletion include festival records. Registrations cannot grant roles, laboratory acceptance or badges. CSV exports neutralize spreadsheet formulas.

The form is inspiration: correct its outdated Cusco motivation option to a location-neutral choice. Account email is authoritative. Optional demographic/accessibility fields stay private, are never added to public profiles, and are not saved in browser storage. Enrollment is pre-registration subject to venue capacity. Sensitive fields remain optional.

The navigation reflects Programa / Comunidad / Recursos / Conocimiento / Mi panel. Existing community and catalog capabilities remain available. A community hub highlights FIIU, urban meetups and events; knowledge connects to existing courses and resources. Published festival news appear on the dashboard, along with the member's registration and earned badges. Only administrator-confirmed attendance earns a badge. News/resources use real published content and honest empty states.

Design follows NODAL's Montserrat typography and green identity: forest #3d5c38, leaf #59bc53, pale green #dcebd6, white #ffffff, ink #20291e. A broad festival title and compact date/venue panel lead into a readable day-by-day programme. Registration uses grouped fieldsets with a visible saved state; the public-official branch stays next to the programme choices. All controls work on mobile, with keyboard focus and English/Spanish/Portuguese interface text.
